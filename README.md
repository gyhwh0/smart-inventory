# 智能库存查询助手‑Inventory‑Query‑Streamlit

> 
> 📦 基于 Streamlit + DeepSeek AI + Pandas Excel 的食品仓储智能库存查询系统
> 自然语言查询库存、批次、临期、过期商品；网页开箱即用，手机浏览器直接访问；支持管理员上传更新 Excel 库存表；完整日志记录；适合中小型食品配送、仓储内部使用。


## 📖 项目简介
一个非常简易的库存查询系统

本项目是面向**食品仓储 / 食材配送企业**的轻量智能库存查询网页应用。
不需要部署复杂数据库，数据源直接使用 Excel (xlsx) 库存表格。员工在网页输入自然语言，AI 自动提取商品关键词，支持普通库存查询、批次查询、临期商品查询、过期商品查询。

### ✨核心功能

1. **自然语言智能查询**
   - 示例：`帮我查一下可口可乐还有多少`、`查临期商品`、`有没有过期的货`、`批次260606`
   - DeepSeek‑AI 提取关键词；AI 不可用时自动降级为本地规则提取
2. **多维度检索**：商品名称、品类、规格、批次、货物状态模糊匹配
3. **临期 / 过期商品专项查询**
   - 支持自定义天数临期筛选，例如：`查60天内到期商品`
   - 自动识别已过期货物，按剩余天数排序
4. **管理员后台**
   - 通过 URL 参数 `?admin=yes` 打开后台，上传新版 xlsx 库存表，一键替换数据源
   - 上传自动校验 Excel 必填字段，格式错误给出提示
   - 后台查看实时运行日志
5. **全局统计看板**：总商品条目、库存合计、零负库存统计、批次数、30 天临期统计
6. **前端筛选**：品类多选筛选、只看有库存、只看 30 天临期商品
7. **结果导出**：查询结果一键导出 CSV 文件，方便复制到 Excel
8. **完整日志系统**：自动滚动日志，记录访问、查询、上传、异常报错；按会话 ID 区分用户
9. **跨设备访问**：电脑、手机浏览器均可打开；局域网 / 公网服务器部署均可
10. **健壮容错**：Excel 字段缺失校验、AI 调用失败降级、数据清洗去除单元格多余空格、时间 / 数字类型自动转换

### 📌适用场景

- 食材配送、干货仓库内部员工快速查库存
- 不想搭建 MySQL 数据库，直接基于 Excel 库存台账
- 内部几十人使用，轻量低成本，不需要前端开发

## 🗃️ 库存 Excel 模板要求

> 
> 文件名固定：`aa.xlsx`，必须严格遵守列名，**列名中文、符号不能修改**。

### 必填列（缺一不可）

表格

| 列名 | 说明 |
| --- | --- |
| 商品名称 | 商品完整名称，检索核心字段 |
| 品类 | 商品分类，例如饮料、干货 |
| 规格 | 包装规格 |
| 总数量（最小单位） | 库存总数量（最小计量单位） |
| 整件数量 | 整件库存 |
| 散装数量 | 散货库存 |

### 选填列（程序自动兼容，没有会自动创建空列）

`入库`、`出库`、`退货`、`批次`、`生产日期`、`保质期(月)`、`到期日`、`剩余天数`、`货物状态`

> 
> 临期、过期功能依赖：`剩余天数`字段；
> 日期格式建议 Excel 保存为日期格式；数字列不要填文字。

## ⚙️环境变量配置

项目读取密钥优先顺序：`操作系统环境变量` → `streamlit secrets` → `.env`本地文件。

项目根目录新建 `.env` 文件

```
DEEPSEEK_API_KEY=sk‑xxxxxxxxxxxxxxxxxxxxxxxxxxxx
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

- `DEEPSEEK_API_KEY`：DeepSeek 平台 API 密钥
- `DEEPSEEK_BASE_URL`：接口地址，默认不用修改

> 
> ⚠️ `.env` 文件包含密钥，严禁提交到 GitHub！

## 🚀本地运行（Mac / Linux）

### 1. 克隆项目

```
git clone https://github.com/你的用户名/Inventory‑Query‑Streamlit.git
cd Inventory‑Query‑Streamlit
```

### 2. 创建 & 激活虚拟环境

```
python3 -m venv .venv
source .venv/bin/activate
```

### 3. 安装依赖

```
pip install -r requirements.txt
```

`requirements.txt`内容：

```
streamlit>=1.40.0
pandas>=2.2
openpyxl>=3.1
openai>=1.50
python‑dotenv>=1.0
```

### 4. 准备库存文件

两种方式任选其一

1. 放入符合格式的 `aa.xlsx` 到项目根目录
2. 先运行程序，访问管理员后台 `http://127.0.0.1:8501?admin=yes`，上传库存表格

### 5. 启动项目

> 
> ❗不要用 python app.py，必须使用 streamlit 命令启动

```
streamlit run app.py
```

程序启动成功输出：

```
Local URL: http://localhost:8501
Network URL: http://192.168.x.x:8501
```

- 本机访问：`http://localhost:8501`
- **管理员后台**：`http://localhost:8501?admin=yes`
- 手机同局域网访问：打开 `Network URL` 地址

## 🛠️常见问题 & 排错手册

### 1. ModuleNotFoundError

确认已经激活虚拟环境，依赖已经执行 `pip install -r requirements.txt`。

### 2. 启动后提示：没有找到 aa.xlsx

两种解决：

- 根目录放置格式正确`aa.xlsx`
- 访问 `?admin=yes` 管理员后台上传库存表。

### 3. 上传 Excel 提示缺少必要列

Excel 表头必须严格匹配项目文档的**必填列**，中文符号、空格不能多。

### 4.AI 不工作 / 关键词提取失败

1. 检查`.env`密钥是否正确，密钥前后不要多余空格换行
2. DeepSeek 账号余额是否充足
3. 网络是否可以访问 API 接口

> 
> AI 调用异常会自动降级为本地规则关键词提取，程序不会崩溃。

### 5. 手机浏览器打不开网页

1. 局域网：手机电脑连接同一个 WiFi；使用 Network IP 访问；关闭电脑防火墙。
2. 云服务器部署：确认安全组已经放行 8501 端口。

### 6. 上传新 Excel，数据没有更新

代码内部调用 `st.cache_data.clear()` 清理缓存；确认上传没有报错。

### 7. 临期、过期查询没有结果

检查 Excel `剩余天数` 字段，必须是数字，不要填写文字。
